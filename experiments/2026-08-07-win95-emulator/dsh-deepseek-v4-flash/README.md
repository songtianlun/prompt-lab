# Windows 95 网页模拟器

一个用纯 HTML / CSS / JavaScript 构建的高还原度 Windows 95 桌面环境模拟器。
零依赖、无构建步骤，直接双击 `index.html` 即可在浏览器中运行。

## 运行方式

**方式一（最简单）**：直接双击打开 `index.html`。

**方式二（本地服务器，推荐）**：

```bash
cd win95-dsh
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 提示：首次打开会显示 Windows 95 开机画面（约 5 秒，单击可跳过），
> 随后出现“欢迎使用 Windows 95”窗口。

## 功能一览

### 系统级
- **开机动画**：黑色背景 + Windows 标志 + 进度条，“Starting Windows 95…” 风格
- **关机/重启**：“开始 → 关闭系统”提供 待机 / 关闭 / 重启 / MS-DOS 方式 四种选项
  - 关闭：显示经典黑屏 “It's now safe to turn off your computer.”
  - 重启：重新播放开机动画
  - MS-DOS：进入真实可用的命令行，键入 `win` 或 `exit` 返回
- **窗口管理**：拖动、八方向缩放、最小化/最大化/还原、双击标题栏最大化、焦点置顶、
  任务栏按钮、Alt+F4 关闭、任务栏右键层叠/平铺/最小化所有
- **虚拟文件系统**：我的电脑（A: 软盘 / C: 硬盘 / D: 光驱），文件可新建/删除(进回收站)/重命名，
  数据通过 localStorage 持久化

### 桌面
- 我的电脑、网上邻居、回收站、我的文档、记事本、扫雷、纸牌等图标
- 图标可自由拖动、框选、右键菜单（排列图标 / 对齐 / 新建 / 属性）
- 右键桌面打开“显示器 属性”

### 开始菜单
- 程序（附件：画图/记事本/计算器/游戏/MS-DOS 方式、资源管理器、欢迎）
- 文档（最近打开的文件）、设置（控制面板/任务栏）、查找、帮助、运行、关闭系统
- 全部为级联菜单，支持悬停展开

### 常用程序
| 程序 | 说明 |
| --- | --- |
| 记事本 | 打开/保存（虚拟文件系统）、查找、时间/日期、Ctrl+S |
| 画图 | 14 种工具（铅笔/刷子/喷枪/填充/取色/放大/直线/矩形/多边形/椭圆/圆角/文字/橡皮/选择），28 色调色板，翻转/拉伸，缩放，保存 PNG |
| 计算器 | 标准/科学型切换、十六/十/八/二进制、内存功能、键盘输入 |
| 扫雷 | 完整可玩：三档难度、旗/问号、连环翻开、计时、LED 数码管计数 |
| 纸牌 | 完整可玩 Klondike：拖拽、翻一张/三张、双击自动上叠、背面图案选择、自动完成动画 |
| 资源管理器 | 目录树 + 文件列表（大图标/小图标/列表/详细资料）、地址栏、新建/删除/重命名、属性 |
| MS-DOS | 迷你命令行：dir/cd/cls/type/copy/del/md/rd/ren/mem/tree/help 等，命令历史 |
| 控制面板 | 显示/鼠标/键盘/日期时间/声音/系统/添加删除程序/字体/网络/区域/多媒体 |
| 帮助 | 分类帮助主题，可点击跳转 |

### 设置（控制面板 → 显示）
- **背景**：蓝天白云、气泡、安装程序等墙纸，居中/平铺/拉伸，实时预览
- **屏幕保护程序**：变幻线、星空、字幕，空闲自动激活
- **外观**：多套配色方案（高对比度/梅紫/玫瑰等），实时改变整个界面
- **设置**：分辨率 640×480 / 800×600 / 1024×768（缩放模拟）

### 其它细节
- 经典 3D 浮雕控件、像素风字体（联网时加载 “Pixelated MS Sans Serif”，离线回退 Tahoma）
- 任务栏时钟、双击打开日期/时间属性、任务栏可自动隐藏
- WebAudio 合成的开机/关机音效与提示音（可在“声音”中关闭）
- 开机后的“单击这里开始”提示气泡
- Alt+F4 / Ctrl+Esc / F1 快捷键

## 目录结构

```
win95-dsh/
├── index.html          入口页面
├── css/
│   ├── win95.css       核心 UI（窗口/任务栏/开始菜单/控件/开机画面）
│   └── apps.css        应用与细节样式
├── js/
│   ├── w95.js          核心库：像素图标系统、虚拟文件系统、设置、音效
│   ├── wm.js           窗口管理器（拖拽/缩放/焦点/任务栏联动）
│   ├── dialogs.js      消息框、运行对话框、文件对话框、级联菜单
│   ├── desktop.js      桌面图标、任务栏、开始菜单、右键菜单
│   ├── boot.js         开机/关机/重启流程、屏幕保护
│   ├── main.js         入口
│   └── apps/           各程序：notepad/calc/paint/minesweeper/solitaire/
│                       explorer/msdos/controlpanel/props/misc/help/welcome
└── test/               自动化测试（CDP，无外部依赖）
    ├── verify.mjs      39 项功能断言测试
    └── e2e.mjs         端到端截图测试
```

## 自动化测试

需要本机有 Chrome/Chromium（脚本会自动连接远程调试端口）：

```bash
node test/verify.mjs ~/.cache/ms-playwright/chromium-1234/chrome-linux64/chrome \
    "file://$PWD/index.html"
```
