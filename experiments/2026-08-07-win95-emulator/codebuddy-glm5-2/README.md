# Windows 95 模拟器 (Svelte)

使用 Svelte 4 + Vite 5 实现的 Windows 95 桌面环境模拟器，还原经典操作系统体验。

## 功能特性

### 桌面环境
- 经典青色桌面壁纸，可切换 5 种壁纸（青色/深蓝/森林/图案/云彩）
- 桌面图标，双击打开应用
- 右键桌面弹出上下文菜单
- 底部任务栏，显示开始按钮、运行中任务、系统托盘时钟
- 开始菜单，按分组列出所有程序

### 窗口管理
- 可拖拽标题栏移动窗口
- 双击标题栏最大化/还原
- 最小化、最大化、关闭按钮
- 右下角拖拽调整窗口大小
- 窗口聚焦 z-index 管理
- 点击任务栏切换窗口

### 内置应用

| 应用 | 说明 |
|------|------|
| **记事本** | 文本编辑，支持文件/编辑/格式菜单，自动换行，保存为 .txt |
| **画图** | 铅笔/橡皮/填充/直线/矩形/椭圆工具，28 色调色板，画笔粗细，保存为 .png |
| **扫雷** | 9×9 网格 10 个雷，左键揭开、右键插旗，自动展开空白区域，计时器 |
| **计算器** | 四则运算、内存功能(MC/MR/MS/M+)、平方根/倒数/百分比/正负 |
| **我的电脑** | 显示驱动器(A:/C:/D:)和文件夹，双击进入文件管理器 |
| **文件管理器** | 模拟文件系统，前进/后退/上一级导航，文件列表 |
| **控制面板** | 壁纸切换、主题颜色设置、关于信息三个标签页 |
| **关于** | Windows 95 版本信息对话框 |

### 视觉还原
- 经典 3D 斜面边框（凸起/凹陷效果）
- MS Sans Serif 字体回退链
- 标题栏蓝色渐变
- 像素艺术 SVG 图标
- 经典按钮按下效果
- Win95 风格滚动条

## 技术栈

- **Svelte 4** - 响应式 UI 框架
- **Vite 5** - 构建工具与开发服务器
- **原生 CSS** - 还原 Win95 视觉风格（CSS 变量 + 斜面边框）
- **Svelte Store** - 窗口管理状态

## 项目结构

```
src/
├── App.svelte              # 主应用，组合所有组件
├── main.js                 # 入口
├── app.css                 # 全局 Win95 样式系统
├── components/
│   ├── Desktop.svelte      # 桌面（图标、右键菜单、壁纸）
│   ├── Taskbar.svelte      # 任务栏（开始按钮、任务列表、时钟）
│   ├── StartMenu.svelte    # 开始菜单
│   └── Window.svelte       # 可拖拽窗口组件
└── lib/
    ├── stores.js           # 窗口管理 store
    ├── registry.js         # 应用注册表与图标
    └── apps/
        ├── Notepad.svelte
        ├── Paint.svelte
        ├── Minesweeper.svelte
        ├── Calculator.svelte
        ├── MyComputer.svelte
        ├── Explorer.svelte
        ├── Settings.svelte
        └── About.svelte
```

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

开发服务器默认运行在 `http://localhost:5173`。

## 使用说明

1. **打开应用**：双击桌面图标，或点击"开始"菜单选择程序
2. **移动窗口**：拖拽标题栏
3. **最大化**：双击标题栏，或点击 □ 按钮
4. **最小化**：点击 _ 按钮，或点击任务栏对应项
5. **关闭窗口**：点击 ✕ 按钮
6. **调整大小**：拖拽窗口右下角
7. **切换壁纸**：打开控制面板 → 显示 → 选择壁纸
8. **扫雷**：左键揭开，右键插旗
